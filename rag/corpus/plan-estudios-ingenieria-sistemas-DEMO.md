# Plan de estudios de Ingeniería de Sistemas

## 1. Datos generales

- **Programa:** Ingeniería de Sistemas, Facultad de Ingeniería.
- **Duración:** 8 semestres.
- **Créditos totales del plan:** 134.
- **Componentes:** asignaturas obligatorias, electivas, cursos del Menor (cuatro, uno por semestre desde quinto) y Práctica Profesional en octavo semestre.
- Los Cursos de Competencias Digitales (insignia) no suman créditos al plan de estudios, pero la insignia es requisito de grado y de la Práctica Profesional.

## 2. Reglas de avance

1. Un estudiante puede matricular como máximo **20 créditos por semestre**.
2. Una asignatura se aprueba con nota final igual o superior a **3.0**, en escala de 0 a 5.
3. Para matricular una asignatura hay que tener aprobados sus **prerrequisitos**. Un **correquisito** se puede cursar en el mismo semestre.
4. La **Práctica Profesional** exige **110 créditos aprobados** y la **insignia de competencias digitales** completa.
5. La proyección de semestres restantes se calcula con los créditos pendientes divididos entre 20 y con la cadena más larga de prerrequisitos pendientes; se toma el mayor de los dos valores.

## 11. Cadenas de prerrequisitos

Las cadenas largas determinan el mínimo de semestres que le quedan a un estudiante, aunque tenga pocos créditos pendientes. Reprobar una asignatura de una cadena retrasa todas las que dependen de ella.

- **Programación y software:** Razonamiento Algorítmico → Programación Orientada a Objetos → Estructura de Datos → Arquitectura de Software → Ingeniería de Software → Calidad de Software.
- **Desarrollo web y móvil:** Programación Orientada a Objetos → Desarrollo Frontend → Desarrollo Backend → Desarrollo de Aplicaciones Móviles.
- **Bases de datos:** Estructura de Datos → Diseño de Bases de Datos → Gestión de Bases de Datos.
- **Matemáticas y física:** Cálculo Diferencial → Cálculo Integral → Cálculo en Varias Variables.
- **Física:** Cálculo Diferencial → Mecánica → Electromagnetismo.
- **Datos e inteligencia artificial:** Estadística Descriptiva → Ciencia de Datos e Inteligencia Artificial → Sistemas Inteligentes.
- **Investigación e innovación:** Estadística Descriptiva → Ingeniería Basada en Evidencia → Soluciones Innovadoras.
- **Infraestructura:** Infraestructura Tecnológica → Servicios Cloud e IoT.
- **Menor:** Cursos Menor - Ing. Sistemas I → Cursos Menor - Ing. Sistemas II → Cursos Menor - Ing. Sistemas III → Cursos Menor - Ing. Sistemas IV.

## 12. Recomendaciones para avanzar sin retrasos

1. Priorizar cada semestre las asignaturas que abren cadenas largas (Razonamiento Algorítmico, Programación Orientada a Objetos, Cálculo Diferencial y Estadística Descriptiva).
2. Si se reprueba una asignatura con prerrequisitos que dependen de ella, repetirla en el semestre siguiente.
3. Completar la insignia de competencias digitales antes de llegar a 110 créditos, para no aplazar la Práctica Profesional.
4. Elegir los cursos de competencias digitales que más se relacionen con las asignaturas del semestre (por ejemplo, Habilidades en Analítica Digital junto con Estadística Descriptiva).
